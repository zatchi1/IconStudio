# Icon Studio

تطبيق أندرويد (Kotlin) لإنشاء اختصارات مخصصة على الشاشة الرئيسية بصورة واسم من اختيارك، تفتح التطبيق الأصلي عند الضغط عليها.

- الحد الأدنى: Android 9 (API 28) — الهدف: Samsung Galaxy A20
- بدون إنترنت، بدون حساب، بدون إعلانات، بدون روت، بدون أي صلاحية خطرة
- المكتبات: AndroidX Core / AppCompat / RecyclerView + Material Components فقط (كلها تدعم Android 9)

## ما الذي يفعله (وما الذي لا يفعله)

أندرويد لا يسمح لأي تطبيق بتغيير أيقونة تطبيق آخر داخل النظام أو درج التطبيقات.
لذلك ينشئ Icon Studio **اختصارًا جديدًا** على الشاشة الرئيسية (عبر `ShortcutManager`)
يحمل صورتك واسمك، ويفتح التطبيق الأصلي. الأيقونة الأصلية تبقى كما هي، ويمكنك إخفاؤها أو
إزالتها من الشاشة الرئيسية بنفسك. عند الإضافة يعرض النظام نافذة تأكيد، وهذا هو إذن المستخدم.

## بناء الـ APK

### الطريقة 1: Android Studio (الأسهل)
1. ثبّت Android Studio (إصدار Koala 2024.1 أو أحدث).
2. `File > Open` ثم اختر مجلد `IconStudio`.
3. انتظر انتهاء Gradle Sync (سينزّل Android SDK 34 وGradle 8.7 تلقائيًا؛ يحتاج إنترنت أول مرة).
   إن طلب منك تنزيل SDK Platform 34 فوافق.
4. `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
5. الملف: `app/build/outputs/apk/debug/app-debug.apk`

### الطريقة 2: سطر الأوامر
يلزم JDK 17+ وAndroid SDK (متغير `ANDROID_HOME`).
```
./gradlew assembleDebug
```
أو نسخة release (موقّعة بمفتاح debug للاستخدام الشخصي):
```
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
```

## التثبيت على Galaxy A20
- عبر USB: فعّل «خيارات المطوّر» ثم «تصحيح USB»، ثم `adb install app-debug.apk`
- أو انسخ الملف إلى الهاتف وافتحه، وفعّل «التثبيت من مصادر غير معروفة» لتطبيق مدير الملفات عند الطلب.

## طريقة الاستخدام
1. افتح التطبيق، واختر تطبيقًا من تبويب «التطبيقات» (يوجد بحث بالاسم).
2. اضغط «اختيار صورة» (معرض الصور أو أي مصدر صور على الهاتف، PNG/JPG) أو استخدم «الأيقونة الأصلية».
3. حرّك الصورة بإصبع، وكبّر/صغّر بإصبعين، وأدرها بزر ٩٠° أو شريط التدوير الدقيق، واختر الخلفية (شفاف/أسود/أبيض/رمادي).
4. اكتب الاسم الظاهر (مثلًا BLACK).
5. اضغط «إضافة إلى الشاشة الرئيسية» ثم أكّد في نافذة النظام.
6. من تبويب «أيقوناتي»: اضغط على أيقونة لتعديلها (يتم تحديث الاختصار الموجود على الشاشة)، أو سلة المهملات لحذفها.

## ملاحظات
- حذف أيقونة من التطبيق يعطّل الاختصار ويمسح الصورة والإعدادات، لكن أندرويد لا يسمح للتطبيق بإزالة الأيقونة من الشاشة الرئيسية؛ اضغط عليها مطولًا وأزلها.
- إن لم يدعم لانشر الهاتف إضافة الاختصارات ستظهر رسالة بذلك. لانشر Samsung One UI الافتراضي يدعمها.
- كل المعالجة محلية: الصور تُحفظ في التخزين الخاص بالتطبيق فقط، والتطبيق لا يملك صلاحية INTERNET.

## هيكل الكود
| الملف | الدور |
|---|---|
| `MainActivity.kt` | قائمة التطبيقات + أيقوناتي + البحث |
| `EditorActivity.kt` | المحرّر: اختيار الصورة، الاسم، الحفظ، إنشاء/تحديث الاختصار |
| `EditorView.kt` | واجهة القص: سحب، تكبير، تدوير، خلفيات، تصدير الصورة النهائية |
| `ShortcutHelper.kt` | إنشاء/تحديث/تعطيل الاختصارات عبر ShortcutManager |
| `IconStore.kt`, `IconEntry.kt` | الحفظ الدائم (JSON + ملفات صور في التخزين الخاص) |
| `ImageUtils.kt` | قراءة الصور بحجم مناسب مع تصحيح اتجاه EXIF |
